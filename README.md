# job-market-dashboard
U.S. Job Market Dashboard
An interactive dashboard for exploring U.S. employment and wage data by state and county. Users can filter by state and metric to view a choropleth map, county-level bar chart, regional box plot, and a summary data table.

# Data Source
U.S. Bureau of Labor Statistics — Employment and Wages Data Viewer
https://data.bls.gov/cew/apps/data_views/data_views.htm#tab=Tables
